# Sands of Empire

Пошаговая 4X-стратегия про Левант около 1187 года, эпоху крестовых походов. Сделана на Unity.

## Что внутри

- 6 играбельных сторон на гексагональной карте Леванта
- Дипломатия: отношения, претензии на земли, перемирия, пакты и союзы
- Торговля между странами
- ИИ с разными характерами и целями, коалиции против сильнейшего
- Сценарии «Исторический 1187» и «Мирное развитие»
- Сохранение и загрузка партии

## Сборка и запуск

1. Установите Unity **6000.3.25f1**.
2. Откройте папку проекта в Unity Hub.
3. В меню редактора выберите **Runeterra → Build Linux**.
4. Готовая сборка появится в папке `Builds/`.
